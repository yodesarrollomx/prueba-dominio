# Instrucciones para agentes

Este repositorio está fuera del alcance funcional de la auditoría YOD OS.
Consulta el [atlas central](https://github.com/yodesarrollomx/yod-portal/blob/main/docs/arquitectura/README.md) antes de proponer conexiones nuevas.
Lee las instrucciones locales y el README que existan. Conserva el propósito de prueba del dominio.
No publiques secretos, datos personales ni información de repositorios privados.
No se ha activado aquí un flujo de validación arquitectónica ni se afirma cobertura funcional.

## Recuperación eficiente y auditoría (integración propuesta)

Consultar la [política transversal YOD OS](https://github.com/yodesarrollomx/yod-portal/blob/main/docs/agentes/politica-eficiencia-yod-os.md) cuando esté publicada en la rama principal del portal.
